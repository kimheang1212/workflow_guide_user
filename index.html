ការកំណត់រូបរាង Appearance

ផ្លាស់ប្តូរទម្រង់បង្ហាញរបស់ប្រព័ន្ធ។ អ្នកប្រើប្រាស់អាចជ្រើសរើសបានតែ៖ Change the system display mode. Users can only select:

  • ស្វ័យប្រវត្តិ (Auto) Auto
  • ទម្រង់ភ្លឺ (Light) Light
  • ទម្រង់ងងឹត (Dark) Dark
1

បើកការកំណត់រូបរាង Open Appearance Settings

ចុចលើរូបតំណាង Appearance នៅផ្នែកខាងលើខាងស្តាំ។ Click the Appearance icon in the top navigation.

2

ជ្រើសរើសទម្រង់ភ្លឺ Select Light Mode (Example)

ជ្រើសរើស ទម្រង់ភ្លឺ ឬ Light ពីបញ្ជី។ អ្នកអាចជ្រើសរើស ស្វ័យប្រវត្តិ (Auto) ឬ ទម្រង់ងងឹត (Dark) ដោយរបៀបដូចគ្នា។ Select Light from the options. You can select Auto or Dark in the same way.

3

ការកំណត់រក្សាទុកដោយស្វ័យប្រវត្តិ Settings Save Automatically

ប្រព័ន្ធនឹងអនុវត្តនិងរក្សាទុកទម្រង់បង្ហាញដែលបានជ្រើសរើសដោយស្វ័យប្រវត្តិ។ The system applies and saves the selected display mode automatically.

🖼️

ពណ៌រូបរាង Theme Color

ផ្លាស់ប្តូរពណ៌រូបរាងសំខាន់របស់ប្រព័ន្ធដើម្បីផ្គូផ្គងនឹងចំណង់ចំណូលចិត្តរបស់អ្នក។ Change the system accent color to match your preferences.

1

បើកការកំណត់ពណ៌ Open Color Settings

ចុចលើរូបតំណាង Theme Color នៅផ្នែកខាងលើ។ Click the Theme Color icon in the top navigation.

2

ជ្រើសរើសពណ៌ Choose Your Color

ជ្រើសរើសពណ៌ពីបញ្ជីពណ៌ដែលមាន។ Select a color from the available color palette.

3

ពន្យារពេលកំណត់ Apply Changes

ពណ៌នឹត្រូវអនុវត្តទៅលើម៉ឺនុយ ប៊ូតុង និងធាតុផ្សេងៗ។ The color will be applied to menus, buttons, and other elements.

ចុចដើម្បីបើកពេញអេក្រង់ Click to Enter Full Screen

ចុចលើរូបតំណាង Full Screen ដើម្បីបើករបៀបពេញអេក្រង់។ Click the Full Screen icon to enter full-screen mode.

ស្វែងរកក្រុមហ៊ុន Search Company

ប្រើសម្រាប់ស្វែងរកព័ត៌មានក្រុមហ៊ុន ដោយបញ្ចូលលេខកូដ ឈ្មោះ អ៊ីមែល លេខទូរស័ព្ទ ឬអាសយដ្ឋាន។ ប្រព័ន្ធនឹងបង្ហាញលទ្ធផលដែលត្រូវនឹងពាក្យស្វែងរក។ Use this function to find company information by entering a code, name, email, phone number, or address. The system displays matching results.

1

ចូលទៅកាន់ក្រុមហ៊ុន Go to Company

ចុចលើ ក្រុមហ៊ុន > ក្រុមហ៊ុន។ Go to Company > Company.

2

បញ្ចូលពាក្យស្វែងរក Enter Search Keyword

បញ្ចូលពាក្យស្វែងរកក្នុងប្រអប់ Search។ Enter a keyword in the Search box.

3

មើលលទ្ធផល View Results

ពិនិត្យលទ្ធផលដែលបង្ហាញក្នុងតារាង។ Review the matching results in the table.

នាំចេញជា Excel Export Excel

មុខងារនេះប្រើសម្រាប់នាំចេញបញ្ជីព័ត៌មានក្រុមហ៊ុនទៅជាឯកសារ Excel ដើម្បីរក្សាទុក ឬប្រើប្រាស់បន្ត។ This function exports the company list to an Excel file for saving or further use.

1

ចូលទៅកាន់ផ្នែកក្រុមហ៊ុន Open Company

ចុចលើ ក្រុមហ៊ុន > ក្រុមហ៊ុន នៅក្នុងម៉ឺនុយខាងឆ្វេង។ Click Company > Company from the left sidebar.

2

ចុចប៊ូតុង Excel Click the Excel Button

ចុចលើប៊ូតុង Excel នៅផ្នែកខាងលើនៃតារាងក្រុមហ៊ុន។ Click the Excel button above the company table.

3

រក្សាទុកឯកសារ Save the File

ជ្រើសរើសទីតាំងសម្រាប់រក្សាទុកឯកសារ ហើយចុច Save។ Choose a folder to save the file, then click Save.

4

បើកឯកសារ Excel Open the Excel File

បើកឯកសារ Company.xlsx ដើម្បីមើលព័ត៌មានក្រុមហ៊ុនដែលបាននាំចេញ។ Open the Company.xlsx file to view the exported company information.

1

ចុចប៊ូតុងបន្ថែម Click Add

ចូលទៅកាន់ ក្រុមហ៊ុន > ក្រុមហ៊ុន ហើយចុចប៊ូតុង បន្ថែម នៅផ្នែកខាងលើខាងស្តាំ។ Go to Company > Company, then click the Add button in the top-right corner.

2

បំពេញព័ត៌មានក្រុមហ៊ុន Enter Company Information

បំពេញព័ត៌មានក្រុមហ៊ុនក្នុងទម្រង់។ អ្នកប្រើប្រាស់អាចបំពេញតែព័ត៌មានដែលមានសញ្ញា * ជាព័ត៌មានចាំបាច់បាន។ ព័ត៌មានផ្សេងទៀតអាចបំពេញបន្ថែមបាន ប្រសិនបើមាន។ Enter the company information in the form. Users only need to complete fields marked with *, as they are required. Other fields can be completed when the information is available.

  1. ព័ត៌មានក្រុមហ៊ុន / Company Information: បញ្ចូលព័ត៌មានលម្អិតក្រុមហ៊ុន។ Company Information: Enter the company details.
  2. ស្ថានភាពសកម្ម / Active Status: ធីកជម្រើសនេះនៅពេលក្រុមហ៊ុនត្រូវបានធ្វើឲ្យសកម្ម។ Active Status: Tick this option when the company should be active.
  3. រក្សាទុក / Save: ចុចរក្សាទុកបន្ទាប់ពីបញ្ចូលព័ត៌មានចាំបាច់។ Save: Click Save after entering the required information.
3

រក្សាទុកព័ត៌មាន Save Information

បន្ទាប់ពីបំពេញព័ត៌មានចាំបាច់រួច ចុចប៊ូតុង រក្សាទុក ដើម្បីបង្កើតក្រុមហ៊ុនថ្មី។ After completing the required fields, click Save to create the new company.

ចំណាំ Notes

  • អ្នកប្រើប្រាស់អាចបំពេញតែព័ត៌មានដែលចាំបាច់មានសញ្ញា * បាន។ Users may complete only the required fields marked with *.
  • ព័ត៌មានដែលមិនចាំបាច់ អាចបំពេញបន្ថែមនៅពេលមានព័ត៌មាន។ Optional information can be added when available.
  • ចុច បោះបង់ ឬសញ្ញាព្រួញត្រឡប់ក្រោយ ដើម្បីត្រឡប់ទៅទំព័រក្រុមហ៊ុនដោយមិនរក្សាទុកព័ត៌មាន។ Click Cancel or the back arrow to return to the Company page without saving.

បញ្ចូល File Upload File

មុខងារនេះប្រើសម្រាប់ផ្ទុកឯកសារ Excel ដើម្បីបង្កើត ឬបន្ថែមព័ត៌មានក្រុមហ៊ុន និងសាខាច្រើនក្នុងពេលតែមួយ។ This function is used to upload an Excel file to create or add multiple company and branch records at the same time.

1

ចូលទៅកាន់ក្រុមហ៊ុន Open Company

ចូលទៅកាន់ ក្រុមហ៊ុន > ក្រុមហ៊ុន ហើយចុចប៊ូតុង បញ្ចូល File / Upload File នៅផ្នែកខាងលើ។ Go to Company > Company, then click the Upload File button at the top.

2

ទាញយកទម្រង់ Excel Download the Excel Template

ចុចប៊ូតុង ទាញយកគំរូ / Download Template ដើម្បីទាញយកឯកសារ Excel គំរូសម្រាប់បំពេញព័ត៌មានក្រុមហ៊ុន និងសាខា។ Click Download Template to download the Excel template for company and branch information.

3

រក្សាទុកឯកសារគំរូ Save the Template File

ជ្រើសរើសទីតាំងសម្រាប់រក្សាទុកឯកសារ បន្ទាប់មកចុច Save។ Choose a folder to save the file, then click Save.

4

បំពេញព័ត៌មានក្នុង Excel Fill in the Excel File

បើកឯកសារ Excel ដែលបានទាញយក ហើយបំពេញព័ត៌មានតាមជួរឈរខាងក្រោម៖ Open the downloaded Excel file and fill in the following columns:

  • Company_Code — លេខកូដក្រុមហ៊ុន Company_Code — Company code
  • Company_Name — ឈ្មោះក្រុមហ៊ុន Company_Name — Company name
  • Branch_Code — លេខកូដសាខា Branch_Code — Branch code
  • Branch_Name — ឈ្មោះសាខា Branch_Name — Branch name

អាចបំពេញព័ត៌មានក្រុមហ៊ុនតែប៉ុណ្ណោះបាន ប្រសិនបើមិនមានព័ត៌មានសាខា។ Users may enter only company information when branch information is not available.

5

ជ្រើសរើសឯកសារ Excel Select the Excel File

ត្រឡប់មកទំព័រ បញ្ចូល File / Upload File ហើយអូសឯកសារ Excel ទម្លាក់ក្នុងប្រអប់ផ្ទុកឯកសារ ឬចុចលើប្រអប់ដើម្បីជ្រើសរើសឯកសារ។ Return to the Upload File page and drag the completed Excel file into the upload area, or click the upload area to select a file.

ប្រព័ន្ធគាំទ្រតែឯកសារ .xlsx ប៉ុណ្ណោះ។ Only .xlsx files are supported.

6

ពិនិត្យបញ្ជីទិន្នន័យមុនបញ្ចូល Review Data Before Upload

បន្ទាប់ពីជ្រើសរើសឯកសារ ប្រព័ន្ធនឹងបង្ហាញបញ្ជីព័ត៌មានក្រុមហ៊ុន និងសាខាដែលបានអានពីឯកសារ។ សូមពិនិត្យព័ត៌មានទាំងអស់មុនចុចរក្សាទុក។ After selecting the file, the system displays the company and branch records read from the Excel file. Review all data before saving.

  • ពិនិត្យចំនួនព័ត៌មានដែលអាចបញ្ចូលបាន។ Check the number of valid records.
  • ពិនិត្យចំនួនព័ត៌មានដែលមានបញ្ហា។ Check the number of records with issues.
  • ចុចព្រួញនៅមុខធាតុនីមួយៗ ដើម្បីមើលព័ត៌មានលម្អិត។ Click the arrow beside each item to view details.
  • លុបព័ត៌មានដែលមិនត្រឹមត្រូវ ដោយចុចរូបតំណាងលុប។ Remove incorrect records by clicking the delete icon.
  • ទុកតែព័ត៌មានត្រឹមត្រូវសម្រាប់បញ្ចូលទៅក្នុងប្រព័ន្ធ។ Keep only valid records for upload.
7

រក្សាទុកព័ត៌មាន Save Information

បន្ទាប់ពីពិនិត្យបញ្ជីទិន្នន័យរួច ចុចប៊ូតុង រក្សាទុក / Save ដើម្បីបញ្ចូលព័ត៌មានត្រឹមត្រូវទៅក្នុងប្រព័ន្ធ។ After reviewing the records, click Save to upload the valid information into the system.
